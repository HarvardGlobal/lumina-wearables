# Security policy

Do not put patient data, credentials, access tokens, or production endpoints in
GitHub issues, discussions, pull requests, tests, or logs.

For a suspected vulnerability, use GitHub's private security-advisory reporting
for this repository. If that channel is unavailable, contact a repository
maintainer privately. Include affected version, impact, reproduction steps, and
any safe mitigation; do not publish an exploit or sensitive evidence before a
maintainer has assessed it.

Only supported releases receive security fixes. This service is not a clinical
decision-support system and must be deployed behind authenticated, authorized
network access before it processes any real health data.
